## 🚀 Como Executar Localmente

1. Instalar as dependências:
```bash
npm install --legacy-peer-deps
```

2. Iniciar o servidor de desenvolvimento:
```bash
npm start
```

O aplicativo estará disponível em `http://localhost:3005`.

3. Gerar a build de produção:
```bash
npm run build
```
